
# 👓 OptiMate – Optical Shop Management System

OptiMate is a comprehensive Windows desktop application designed to simplify and automate the daily operations of an optical shop. It provides an integrated platform for managing customers, eye examinations, prescriptions, inventory, billing, spectacle orders, laboratory operations, expenses, and business reports.

Built using Electron, React, TypeScript, Node.js, SQLite, and Prisma ORM, OptiMate offers a centralized and offline-first solution for efficient optical shop management.

## ✨ Key Features

### 📊 1. Dashboard
- Centralized overview of optical shop operations.
- Quick access to application modules.
- Business activity summaries.
- Easy navigation across the application.

### 👥 2. Customer Management
- Add, update, search, and manage customer records.
- Maintain customer contact information.
- Organize customer information in a centralized database.
- Access individual customer profiles.

### 👤 3. Customer Profiles
- Dedicated profile for every customer.
- Centralized customer information.
- Access examination and prescription history.
- View associated spectacle orders and billing records.
- Quick actions for customer-related operations.

### 👁️ 4. Eye Examination
- Record in-house eye examination details.
- Maintain right-eye and left-eye examination information.
- Store visual and refractive measurements.
- Associate examination records with customer profiles.
- Maintain examination history.

### 📄 5. Prescription Management
- Create and manage optical prescriptions.
- Maintain right-eye and left-eye prescription details.
- Manage prescription records.
- Access previous prescription information.
- Associate prescriptions with customer profiles.

### 📅 6. Appointment Management
- Schedule customer appointments.
- Manage appointment details.
- Track upcoming and completed appointments.

### 👓 7. Frame Inventory
- Manage spectacle frame records.
- Maintain frame stock information.
- Track frame availability.
- Organize frame inventory.

### 🔍 8. Lens Inventory
- Manage optical lens records.
- Maintain lens specifications.
- Track lens stock and availability.

### 💰 9. GST Billing
- Generate customer bills.
- Manage billing records.
- Calculate applicable GST.
- Maintain transaction information.

### 🛍️ 10. Spectacle Order Management
- Create and manage spectacle orders.
- Associate orders with customer profiles.
- Track order details and status.
- Maintain order history.

### 🧪 11. Laboratory Management
- Manage laboratory orders.
- Maintain lens and spectacle processing information.
- Track laboratory order progress.

### 💸 12. Expenses Management
- Record shop expenses.
- Organize expense information.
- Monitor business expenditure.

### 📈 13. Reports and Analytics
- View business-related reports.
- Monitor sales and operational information.
- Analyze shop performance.

### ⚙️ 14. Settings and Data Management
- Manage application settings.
- Configure application preferences.
- Support local database management.
- Manage application data and backups.

## 🏗️ Application Architecture

OptiMate follows a modular desktop application architecture.

- **Frontend:** React and TypeScript.
- **Desktop Framework:** Electron.
- **Runtime:** Node.js.
- **Database:** SQLite.
- **ORM:** Prisma.
- **Communication:** Electron IPC for secure communication between application processes.

## 💻 Installation and Setup

### Prerequisites
- Node.js
- npm
- Git

### Clone the Repository

```bash
git clone https://github.com/AayushPAdwal/OptiMate.git
cd OptiMate
```

### Install Dependencies

```bash
npm install
```

### Run the Application

Use the development command configured in `package.json`.
